# Universe-1218 Canon Policy

Universe-1218 is an alternate fan continuity. The archive must never make an invented project detail look like official DC canon merely because both appear inside the same fictional interface.

## Authority levels

### DC_OFFICIAL_REFERENCE

Use for facts established by an official DC reference page or equivalent first-party reference.

Current reference set:

- Green Lantern Corps — https://www.dc.com/characters/green-lantern-corps
- John Stewart — https://www.dc.com/characters/john-stewart

Examples: Oa as the Corps' base, hard-light constructs, John Stewart's architectural approach to constructs.

### LANTERNS_2026

Use for facts established by official material about the 2026 television series.

Current reference set:

- Rushville residents / initial premise — https://www.dc.com/blog/2026-08-14/the-lanterns-stars-shine-a-light-on-their-rushville-residents

Examples: Rushville, Nebraska; veteran Hal Jordan and trainee John Stewart investigating a murder in the show's initial premise.

### U1218_ADAPTATION

Use when Universe-1218 takes an established Green Lantern or *Lanterns* concept and adapts it for this interactive continuity.

Examples: the Oan archive interface, the visitor being selected through the investigation, Corps-style service records.

### U1218_ORIGINAL

Use for material authored specifically for this project.

Examples: Incident `2814-E/001`, record `2814-Δ/19`, waveform correlation values, archive relay identifiers, user ring-number syntax, spatial-echo case findings.

## Rules

1. **Observation is not interpretation.** Case measurements, witness claims, archive records, and conclusions are stored/displayed separately.
2. **Source authority is not in-fiction certainty.** A U1218-original measurement can be certain inside the case while still being clearly project-original lore.
3. **Do not invent a canon date to resolve ambiguity.** Universe-1218 chronology should be locked deliberately before an incident year is published.
4. **Do not import official imagery, episode footage, soundtrack recordings, production audio, or scraped promotional art into the repository.**
5. **Physical reference is not an asset source.** Official merchandise may inform a procedural material/silhouette study, but project graphics remain independently implemented.
6. **No unsourced direct quote should be labeled as current-show dialogue.**
7. **New lore-bearing data requires an origin classification.**
8. **When official sources conflict across continuities, store the continuity rather than silently blending them.**

## Ring reference

The current selection-ring study is informed by the licensed *Lanterns* power-ring product reference from DC Shop:

- https://shop.dc.com/products/lanterns-green-lantern-power-ring

The site does not ship those product photos. The procedural study separates the physical ring from emitted energy:

- dark metal body/band
- gold-tone face structure
- green enamel/inlay treatment
- concentric central geometry
- green emission only as an activation effect

The exact color values in CSS are artistic implementation values, not claimed official production color specifications.
